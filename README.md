**PowerBI Super Store Sales Dashboard**

**Project Overview**
This Power BI dashboard provides insights into Super Store sales performance, profit trends, product categories, customer segments, shipping modes, and regional sales distribution.

**Tools Used**

- Power BI
- Excel

**Key Metrics**

- Total Sales: 1.6M
- Total Quantity: 22K
- Total Profit: 175K

**Dashboard Features**

- Sales Analysis by Region
- Sales by Segment
- Payment Mode Analysis
- Category and Sub-Category Analysis
- Monthly Sales and Profit Trends
- Shipping Mode Performance
- Interactive Filters and Visualizations
